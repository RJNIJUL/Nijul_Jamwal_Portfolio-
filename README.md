# Nijul Jamwal — Data Science & AI/ML Portfolio

A dark gothic anime-inspired portfolio website built with **React**, **Vite**, and **Tailwind CSS**.

## Quick Start in VS Code

1. Extract this archive and open the `Nijul_Jamwal_Portfolio` folder in **VS Code**.
2. Open the integrated terminal (`Ctrl + ~` or `Terminal -> New Terminal`).
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the local development server:
   ```bash
   npm run dev
   ```
5. Open the local URL shown in the terminal (usually `http://localhost:5173`).
